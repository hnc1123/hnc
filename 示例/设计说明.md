## 2. 视觉规范

### 2.1 色板

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--bg` | `#080A10` | 页面底色 |
| `--panel` | `#0D1019` | 面板 / 侧栏 |
| `--panel-2` | `#121627` | 悬浮层 |
| `--line` | `rgba(255,255,255,.07)` | 分割线 |
| `--text` | `#EEF2F8` | 主文字 |
| `--text-2` | `#A4ADC2` | 次级文字 |
| `--text-3` | `#6B7488` | 辅助文字 |
| `--mint` | `#3CE3C4` | 主强调色 |
| `--violet` | `#8B7BFF` | 次强调色 |
| `--pink` | `#FF7FB0` | 点缀色 |
| `--grad` | `120deg, #3CE3C4 → #8B7BFF 58% → #FF7FB0` | 主渐变 |

浅色主题作为可选（第 6 天实现），默认深色。

### 2.2 字体与字号

- 字体栈：`"Segoe UI Variable Display", "Segoe UI", "Microsoft YaHei UI", "PingFang SC", system-ui`
- 数字使用 `font-variant-numeric: tabular-nums`（时间、播放量对齐）
- 标题 36 / 19 / 15.5 px；正文 13.5 px；辅助 11~12 px；字距 0~2px 递增

### 2.3 形状与间距

- 圆角：大卡片 22px、封面 16px、按钮/输入框 999px
- 间距基准 4px；区块间距 34px；卡片间距 18px
- 卡片悬停：上移 4px + 阴影加深；播放按钮淡入
- 动效：0.18~0.25s ease；`prefers-reduced-motion` 下全部关闭

### 2.4 图像策略（重要）

**不引用任何外链图片**，保证离线可用、无版权风险：

- 封面 = CSS 多层径向渐变 + 斜纹叠加（6 套预设 `.c1`~`.c6`）
- 图标 = 手写内联 SVG（线性、1.7~1.9 描边）
- 唱片/光盘 = CSS `conic-gradient` + 重复径向渐变
- 后续可加：用 Canvas 根据歌曲名生成"声纹"封面，保证每张不同

## 3. 页面地图

| 页面 | 文件（计划） | 说明 |
| --- | --- | --- |
| 发现首页 | `index.html` | Hero、推荐歌单、排行榜、新碟 |

## 4. 技术约束

- 纯静态：HTML + CSS + 原生 JS，**不使用框架、不连服务器、不引 CDN**
- 数据：`js/data.js` 内置 JSON（虚构内容）
- 持久化：`localStorage`（收藏、最近播放、音量、主题）
- 播放：默认"模拟播放"（进度条、唱片转动、歌词滚动）；本地音乐页可导入真实音频
- 兼容：Chrome / Edge 最新版，1440 宽为主，适配 1024 与 768
