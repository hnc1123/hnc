# 照片目录

把你的照片放进这个文件夹，文件名与 `js/data.js` 里的 `file` 字段一致即可自动显示；
文件不存在时，页面会用同色系渐变占位，不会出现破图。

## 需要 / 可选的文件

| 文件名 | 用途 | 建议尺寸 |
| --- | --- | --- |
| `hero.jpg` | 首页首屏大图 | 长边 2000px 以上，横向 |
| `portrait.jpg` | 关于页 / 首页肖像 | 竖幅 4:5 |
| `p01.jpg` ~ `p18.jpg` | 作品图，对应 `data.js` 中的 18 个条目 | 长边 1600px 左右 |

## 命名与内容对应

| 文件 | 作品 | 系列 |
| --- | --- | --- |
| p01–p05 | 雾起时 / 垭口 / 冷杉线 / 雪线以上 / 云海 | 山与雾 |
| p06–p10 | 末班地铁 / 便利店 / 天桥 / 霓虹雨 / 出租车 | 夜行城市 |
| p11–p15 | 退潮 / 礁石 / 盐田 / 海雾 / 拾贝 | 潮间带 |
| p16–p18 | 侧光 / 窗边 / 旧信 | 静物与手 |

## 说明

- 建议统一转成 JPG，质量 80 左右，单张控制在 500KB 以内，加载更快
- 竖幅、横幅都可以，版式会按图片原始比例自适应
- 如果文件名不同，改 `js/data.js` 里对应条目的 `file` 字段即可
